# Cocolla

Cocolla is intended to become a multi-user embroidery and cross-stitch design application for creating, importing, editing, visualizing, and managing stitching projects. Planned features include an interactive stitch canvas, image-to-pattern conversion, thread color management, front-and-back fabric visualization, pattern exporting, and stitch progress tracking. The implemented foundation currently consists of the UI-independent Milestone 1 stitch engine and versioned pattern document contract.

Created with nexOS.

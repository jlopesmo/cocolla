# Cocolla

Cocolla is a multi-user embroidery and cross-stitch design application for creating, importing, editing, visualizing, and managing stitching projects. Features include an interactive stitch canvas, image-to-pattern conversion, thread color management, front-and-back fabric visualization, pattern exporting, and stitch progress tracking. The modular architecture supports self-hosted deployment and future AI-assisted design features.

Created with nexOS.
